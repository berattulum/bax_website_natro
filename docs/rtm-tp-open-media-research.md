# RTM + TP open-media research log

Research date: 2026-08-06

## Acceptance rule

An asset is approved for the live BaX website only when the source page states a licence that permits commercial web use (CC0, public domain, CC BY, or a similarly explicit licence), the depicted process is technically relevant, and the downloadable file is large enough for its intended layout. “Free download”, an embeddable player, or the absence of a copyright notice is not treated as permission.

## Implementation note

Exact-process, openly licensed HD/4K RTM and thermoplastic-composite footage is scarce. The safe editorial approach is to combine verified open research imagery/animations in smaller evidence modules with high-resolution licensed atmospheric footage in large cinematic panels, always labelling the latter as representative. No asset with an unclear licence should be downloaded into the production repository.
